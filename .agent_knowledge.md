# Developer / Agent Environment Knowledge

## CRITICAL: Database and API Location
- **The database and API are NOT hosted on the local PC.**
- They are hosted on a **remote server**.
- **DO NOT** attempt to query the local database (e.g., using `sqlcmd` or local database utilities on the local PC). Any attempts to connect to a local SQLEXPRESS instance or run SQL queries locally will fail to find the project data and are invalid.
